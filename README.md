# Student Management System - Java

A console-based Java application to manage student records efficiently.

##  Features
- Add new student details (ID, Name, Course, Marks)
- View all student records
- Search student by ID
- Delete student record
- Simple and user-friendly console interface

##  Tech Stack
- Language: Java
- Concepts Used: OOPs, ArrayList, File Handling, Exception Handling
- IDE: VS Code

##  How to Run
1. Clone the repository
2. Open in VS Code
3. Run `StudentManagementSystem.java`
